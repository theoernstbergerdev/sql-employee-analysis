# Employee Data Analysis with SQL

## About the Project

This project uses MySQL to create an employee database and perform data analysis through SQL queries.

## Technologies

* MySQL
* SQL
* MySQL Workbench

## Database Structure

The `funcionarios` table contains:

* Employee ID
* Name
* Age
* Salary
* Department
* Phone number

## SQL Concepts Practiced

* Database and table creation
* Data insertion
* Aggregate functions: `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`
* Filtering with `WHERE`
* Grouping with `GROUP BY`
* Group filtering with `HAVING`
* Sorting with `ORDER BY`
* Unique values with `DISTINCT`
* Handling `NULL` values with `COUNT(column)`
